# Security

Quiet updates itself and is installed with a script, so a weakness in the updater or the install scripts could reach every user. Please report it privately.

## Reporting a vulnerability

Use [Report a vulnerability](https://github.com/stanleykinkelaar/Quiet/security/advisories/new) on GitHub. Please do not open a public issue.

Include what you found, how to reproduce it, and which version and system you used. You will get an answer within a week. Once a fix is released, the advisory is published with credit to you, unless you prefer otherwise.

## What counts

* The updater: checking for, downloading, verifying or installing a new version.
* The install scripts (`install.sh`, `install.ps1`) and the release files.
* Anything that lets another program or user read or change your list.

## Supported versions

Only the latest release gets fixes. Quiet updates itself, so most people already run it.
